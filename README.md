# un-paws!

2d top down where you are kitty and you play rhythm games

play on itch.io: [https://janicedtea.itch.io/un-paws](https://janicedtea.itch.io/un-paws)

## how to play
use arrow keys to move, e to interact, space to progress through dialogue

for the rhythm game, d is left, f is down, j is up, and k is right
